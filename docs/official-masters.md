# レセプト用公式マスターの出典と取り込み

確認日 2026年11月10日

RECEPTは、利用者が公式配布サイトで取得した全件マスターを、院内のRECEPTデータベースへ手動で取り込む方式です。リポジトリとアプリの配布物には公式のマスターデータを同梱せず、RECEPTから配布サイトへの自動取得も行いません。

## 操作手順

1. 厚労省の配布ページで、対象の診療年月に適用される版の全件マスターを選びます。適用開始日と配布ページの更新日は別々に確認します。
2. ダウンロードしたZIPを解凍します。展開したCSVまたはTXTは元のファイル名のまま使用します。表計算ソフトで開いて上書きすると、先頭ゼロや文字コードが変わることがあります。
3. RECEPTの **院内サーバー・マスタ → 公式マスターの取り込み・参照** で、1ファイルずつ選びます。1ファイルの上限は20 MiBです。
4. 「配布ページの更新日」を確認します。ファイル名に日付がある場合は自動で入り、日付のないファイルは配布ページを確認して入力します。令和8年度版の病棟コードの例では、`k.csv` を選び、2026年7月3日を入力します。
5. 「取り込む」を押し、取り込み件数を確認します。7種類の取り込み後、画面上部に「公式マスター 7/7種取込済み」と表示されます。「参照する版」からファイルを選び、コード・名称で検索できます。

取り込み時は、種別ごとの列数、レコード種別、コード形式と重複を確認します。Shift_JIS系の配布ファイルとUTF-8の入力に対応します。不正な行を含むファイルは全体を拒否します。ファイル名、更新日、取込日時、件数、SHA-256、各列の値をSQLiteに保存します。同じ種別・更新日・内容は再登録せず、異なる版はそれぞれ保持します。SHA-256は取り込んだ内容の識別に使います。入手元と全件版であることは、ダウンロード時に利用者が確認します。

既存DBには、更新後の初回アクセスで取込用テーブルが追加されます。「初期サンプルデータに戻す」はデモデータの操作で、取り込み済みマスターは保持されます。

会計・診療入力では、取り込み済みの傷病名と対応する固定点数の外来医科診療行為を新規入力に使います。開発版の診療日は2026年11月10日です。新規入力は、その日以前に更新された取込版のうち各種別の最新の版を参照し、行の収載日・変更日・廃止日などを確認します。投薬・特定器材などの新規算定と、包括・割合・きざみ値などを使う診療行為の新規算定は未対応です。全7種類のコード・名称は取り込み画面で検索できます。点検、算定、請求CSVはデモ用です。
